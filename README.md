# Isaac Ely — Bespoke Tailoring & Couture

An ultra-luxury bespoke tailoring digital experience inspired by editorial haute-couture aesthetics. Crafted for Isaac Ely Bespoke Tailoring, Toronto.

## Key Features

- **Frame-by-Frame Suit Assembly Hero**: 151-frame photorealistic bespoke canvas animation with full-bleed responsive edge-to-edge scaling.
- **Adaptive Precision Header**: Single-row luxury navigation with vector brand mark, bespoke mega-menus, and floating consultation plinth CTA.
- **Single-Scroll Editorial Choreography**: Lenis smooth-scroll engine with synchronized dynamic typography and diamond stitch rails.
- **Essence Expanding Portal**: Full-bleed 3-stage right-to-left wipe (*From Cloth, to Baste, to Bespoke*).
- **Process Diptychs**: Sticky herringbone portrait paired with 5 bespoke stages and founder story.
- **Museum Collection Grid**: Curated 5-column collection gallery with interactive exploration.
- **Interactive 3D Bespoke Medallion**: Double-sided gold coin with scroll-driven 3D rotation parting manifesto text.
- **Consultation Desk**: In-page appointment request desk and interactive bespoke service explorer.
- **Zero-Blur Monumental Footer**: Razor-sharp vector brand mark, studio coordinates, and newsletter concierge.

## Architecture

- **Zero-Dependency Static Architecture**: Pure ES Modules, vanilla CSS, and high-performance HTML5 Canvas.
- **Smooth Scroll Engine**: Bundled local Lenis (`scripts/lenis.js`).
- **Deployment**: Optimized for Vercel with immutable static cache headers for high-density assets and frames.

## Local Development

Open `index.html` via any local static server (e.g., `npx serve .` or VS Code Live Server).
